# Back-end — Orbit Hub API

API REST em **Java 21 + Spring Boot 3**, construída com **Maven**.

> O projeto Spring Boot ainda será gerado. A organização em módulos e camadas está descrita em [`../docs/arquitetura.md`](../docs/arquitetura.md).

## Dependências previstas

- Spring Web, Spring Data JPA, Spring Security, Validation
- PostgreSQL Driver, Flyway
- JWT
- springdoc-openapi (Swagger)
- Spring Boot Actuator, Micrometer (Prometheus)
- JUnit 5, Mockito, Testcontainers, JaCoCo
