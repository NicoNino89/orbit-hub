# Front-end — Orbit Hub Web

SPA em **React + TypeScript**, com build pelo **Vite** e estilos com **Tailwind CSS**.

> O projeto Vite ainda será gerado. Antes de construir o catálogo, a biblioteca de virada de páginas será validada na prova de conceito KAN-58.

## Áreas previstas

| Área | Padrão de interface |
|---|---|
| Descobrir | Catálogo editorial com virada de páginas |
| Conexões | Painel de interesses e Matches |
| Perfil | Cadastro, tese de investimento e dados da startup |

As áreas Comunidade, Serviços e Aprender entram nas fases seguintes.
